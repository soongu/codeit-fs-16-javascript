# 인스타그램 클론 — 자바스크립트 실습 (코드잇 부트캠프 16기)

파트1 웹 퍼블리싱에서 만든 `instagram-clone-html-css` 를 그대로 가져온 폴더입니다.
여기서부터는 HTML/CSS 를 더 쓰지 않고 **자바스크립트로 화면을 움직입니다.**

VS Code Live Server 로 `feed.html` 을 열어서 확인하세요.

- `login.html` — 로그인 화면
- `feed.html` — 피드(타임라인) 화면
- `profile.html` — 프로필 화면
- `css/` — 스타일시트
- `js/` — 자바스크립트 (여기에 `feed.js` 를 옮겨 담습니다)

## 웹 퍼블리싱 때와 다른 점 두 가지

1. `js/` 폴더가 비어 있는 채로 하나 더 있습니다.
2. `css/layout.css` 맨 아래에 `.post-location` 스타일이 한 조각 들어 있습니다.
   게시물의 위치 태그에 붙는 스타일인데, 그 줄은 자바스크립트가 만들어 붙이므로
   퍼블리싱 때는 쓸 일이 없었습니다.

나머지는 여러분이 만든 그 파일과 **글자 하나까지 같습니다.**
